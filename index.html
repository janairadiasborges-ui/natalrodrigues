Siga os passos na ordem. O sorteio fica salvo neste navegador, pode fechar e voltar depois.

1

Esse arquivo já vem com os nomes e o sorteio guardados.

2
Coloque no ar o arquivo que você acabou de baixar

No repositório do site no GitHub, clique em Add file → Upload files, arraste o index.html baixado (ele substitui o antigo; as pastas css, js e imagens continuam lá) e clique em Commit changes. O GitHub Pages leva 1 ou 2 minutos para atualizar.

3
Cole o endereço do site

Confira abrindo o site: tem que aparecer só a tela de digitar o código. Se ainda aparecer o painel do organizador, espere uns minutos e recarregue. Abrir o site

4
Mande o código de cada pessoa

A mensagem leva o endereço do site e o código. O botão WhatsApp abre a conversa com tudo pronto.
